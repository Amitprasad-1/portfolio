# Personal Portfolio Website

A premium, responsive single-page portfolio website showcasing my skills, education, and full-stack web development projects. 

## 🌐 Live Demo
You can view the live website here: [amit-portfolio-six-taupe.vercel.app](https://amit-portfolio-six-taupe.vercel.app)

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Hosting & Automation:** Vercel, GitHub (CI/CD Automated Deployment)

## 🚀 Features
* Clean, minimal design with a responsive layout
* Built-in Dark Mode / Light Mode toggle
* Direct links to my professional social profiles and core projects
